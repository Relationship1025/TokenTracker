# Agent Instructions

Use [CLAUDE.md](./CLAUDE.md) as the single source of truth for this repository's project guidance, architecture notes, and conventions.

This is a **personal, local-only** fork of xiufengsun/TokenTracker: no cloud backend, no accounts, no telemetry, no public releases. Do not reintroduce network dependencies (InsForge, PostHog, update checkers, npm publishing). Data stays in `~/.tokentracker/` on each machine and is merged across machines via the local file transfer feature.
